# ZYNA — Website

The official website for **ZYNA**, the 24/7 AI receptionist.
Tagline: *AI THAT WORKS FOR YOU* — "Never miss a booking again."

Plain React + TypeScript + Vite + Tailwind CSS. No website builders,
no animation libraries — CSS animations and native browser features only.

## Develop

```sh
npm install
npm run dev
```

## Build

```sh
npm run build   # outputs to dist/
```

Pushes to `main` deploy automatically to GitHub Pages via
`.github/workflows/deploy.yml`.
